# ORIGIN X — Image Origin Estimator

> **A calibrated, probabilistic web application that estimates whether an image was created by a human or generated by AI.**

ORIGIN X treats origin estimation as a probabilistic classification task under epistemic uncertainty. It presents calibrated likelihoods, confidence intervals, and an explicit **`INCONCLUSIVE`** abstention state rather than asserting certainty or implying forensic proof.

---

## Key Features

- **Multi-Scale Convolutional Architecture:** Dual-stream forensic CNN (`convnet_multiscale`) capturing both micro-texture sensor shot noise (PRNU) and broader spatial frequency coherence.
- **Calibrated Uncertainty & Abstention:** Post-hoc Temperature Scaling ($T=1.5000$) preventing overconfidence; indeterminate images in the margin $[0.42, 0.58]$ are safely labeled `INCONCLUSIVE`.
- **Zero Train-Test Leakage:** Source/collection-level split isolation across 8 distinct human and AI families; verified on an untouched evaluation set.
- **Shortcut Robustness:** Invariant to corner watermarks, robust against JPEG recompression (Q=50/Q=90), spatial blur, and resampling.
- **Ephemeral In-Memory Processing:** Uploaded images are validated and analyzed strictly in volatile RAM and immediately discarded. Zero disk retention.
- **Apple Design & Fluid Motion:** Restrained studio aesthetic, system typography, WCAG AAA contrast, critically damped spring responses, and full reduced-motion accessibility.

## Quickstart & Usage

### 1. Installation
```bash
py -3.13 -m pip install -r requirements.txt
py -3.13 -m pip install -e . --no-deps
```

### 2. Run Automated Test Suite
```bash
py -3.13 -m pytest tests/ -v
```

### 3. Start Web Application
```bash
py -3.13 -m uvicorn originx.web.app:app --host 127.0.0.1 --port 8000
```
Then open your browser to [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Epistemic Disclaimer
ORIGIN X estimates the probability of human authorship versus AI generation based on spatial and frequency-domain pixel patterns. These results are statistical inferences and do not constitute forensic, legal, or definitive proof of provenance.
